# Privacy Policy for WRhythm

Last Updated: April 19, 2026

WRhythm is a third-party streaming client for user-provided Subsonic-compatible servers such as Navidrome and Gonic. This Privacy Policy explains how the app handles data.

## 1. Summary

- WRhythm does not collect analytics, telemetry, advertising data, or tracking data for the developer.
- WRhythm connects directly to the server configured by the user.
- Data used by the app is stored locally on the device and transmitted to the user-configured server as needed for app functionality.

## 2. Information WRhythm Handles

WRhythm may handle the following information in order to function:

- Server URL
- Username
- Password
- Music library metadata received from the connected server, such as track, album, artist, playlist, and favorite information
- Downloaded audio files saved for offline playback
- Cached cover artwork and other locally cached media metadata

This information is used only to provide app features such as login, browsing a music library, streaming, downloading for offline playback, displaying cover art, and syncing favorite status with the connected server.

## 3. What WRhythm Does Not Do

WRhythm does not:

- collect personal data for the developer
- send analytics or usage statistics to the developer
- use third-party advertising SDKs
- track users across apps, websites, or services
- sell user data

## 4. Local Device Storage

WRhythm stores certain data locally on the device so the app can work properly. Depending on how the app is used, this local storage may include:

- server credentials
- downloaded audio files
- song metadata
- playlist metadata
- radio playlist metadata
- favorite and pending favorite-sync state
- cached images

This data remains on the device unless the user deletes it or uses in-app logout/data removal features.

## 5. Connected Servers

WRhythm is designed to connect to a server chosen or provided by the user. When the app is used, data is transmitted between the device and that connected server in order to:

- authenticate the user
- fetch library and playlist data
- stream audio
- download audio for offline playback
- load cover artwork
- sync actions such as starring or unstarring songs

The privacy practices of the connected server are determined by the operator of that server and the server software being used. WRhythm does not control those server-side privacy practices.

## 6. Network and Security

WRhythm requires network access to communicate with the connected server.

The security of data in transit depends on how the connected server is configured and the URL the user provides. If the server supports HTTPS, users should use HTTPS to protect data during transmission.

## 7. Background Audio

WRhythm uses background audio capability so that audio playback can continue while the app is not in the foreground or while the watch display is off.

## 8. Data Deletion

Users can remove locally stored app data by using the app’s logout and deletion features. Based on current app behavior, logging out removes locally stored credentials, downloads, and related metadata from the device.

## 9. Children’s Privacy

WRhythm is not designed as a children’s app and does not knowingly collect personal information for the developer.

## 10. Changes to This Policy

This Privacy Policy may be updated from time to time. If it is updated, the revised version will be posted with a new “Last Updated” date.
